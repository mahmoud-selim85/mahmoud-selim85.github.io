# Mahmoud Selim, PhD — academic website

This is a Quarto website prepared for free deployment on GitHub Pages.

## Preview locally

Install [Quarto](https://quarto.org/docs/get-started/) and run:

```bash
quarto preview
```

## Publish on GitHub Pages

1. Create a public repository named `mahmoud-selim85.github.io`.
2. Copy these files into the repository and push them to the `main` branch.
3. In repository **Settings → Pages**, choose **GitHub Actions** as the source.
4. The included workflow will render and publish the site automatically.

After deployment, the website will be available at:

<https://mahmoud-selim85.github.io>

The site is intentionally content-first: update the `.qmd` files as your publications, courses, or projects evolve.
